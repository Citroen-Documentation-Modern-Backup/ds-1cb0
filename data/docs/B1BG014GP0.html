B1BG014GP0Appariement : Coussinets de paliers de vilebrequin
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Identification
Figure : b1cg00yd
Le carter-cylindres et le vilebrequin comportent des repères permettant l’appariement des coussinets de palier .
NOTA : Le palier N° 1 est situé côté distribution.
Le repérage est sous forme numérique :
  • De 1 à 3 (Carter-cylindres )
  • De 1 à 2 (vilebrequin)
Il existe 4 classes de coussinets de vilebrequin (Marquage de 2 à 5).
Pour déterminer la classe de coussinets à monter ; Effectuer les opérations suivantes.
Repère sur le vilebrequin + Repère sur le carter-cylindres = Classe de coussinets à monter.
Palier n°1 = a + e.
Palier n°2 = b + f.
Palier n°3 = c + g.
Palier n°4 = d + h.
Exemple .
Palier n°1.
A = 2.
E = 3.
2 + 3 = 5.
Classe de coussinets à monter : N°5.
2. Contrôle des jeux
ATTENTION : Respecter les couples de serrage .
Figure : b1cg00zd
Reposer :
  • Les demi-coussinets de paliers supérieurs
  • Le vilebrequin
Couper 4 morceaux dans la jauge plastique [1] à la largeur des demi-coussinets.
Poser les jauges plastique [1] sur chacune des portées du vilebrequin .
Figure : b1cg010d
ATTENTION : Durant cette opération, le vilebrequin ne doit pas tourner.
Reposer :
  • Les demi-coussinets de paliers inférieurs
  • Les chapeaux de paliers de vilebrequin (/)
ATTENTION : Respecter l’ordre de serrage (de 1 à 8).
Serrer les vis de fixation des chapeaux de paliers au couple.
Figure : b1cg011d
Déposer :
  • Les chapeaux de paliers de vilebrequin (/)
  • Les demi-coussinets de paliers inférieurs
Comparer chaque largeur (en mm) du fil plastique aplati à son point le plus large avec les graduations figurant sur les enveloppes papier.
NOTA : La mesure peut s’effectuer sur le vilebrequin ou le demi-coussinet selon l’adhérence des portées.
La valeur lue indique le jeu de fonctionnement.
NOTA : Le jeu doit être compris entre 0,021 mm et 0,046 mm.
Si les valeurs de jeux sont incorrectes : Remplacer le vilebrequin.
Nettoyer les traces de jauges plastique et huiler le vilebrequin.
Reposer :
  • Les demi-coussinets de paliers inférieurs
  • Les chapeaux de paliers de vilebrequin (/)
