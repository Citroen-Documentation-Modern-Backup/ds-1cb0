2. Opérations préliminaires
NOTA : Les couronnes ABS sont supprimées (la fonction réalisée par les couronnes est transférée vers les roulements de roue avant).
Déposer les transmissions.
3. Remplacement : Soufflet côté boîte de vitesses
3.1. Dépose
Figure : b2fh02ld
Déposer les colliers (1), (2) ; À l’aide d’une pince.
Effectuer un repère entre la transmission (3) et le bol (4) (en "a").
Déposer le bol (4).
Figure : b2fh02md
Déposer le circlips (5).
Figure : b2fh02nd
Effectuer un repère entre la transmission (3) et le tripode (6) (en "b").
Déposer :
  • Le tripode (6) ; À l’aide d’un marteau et d’un chasse-goupille
  • Le soufflet de transmission (7)
3.2. Repose
Poser le soufflet neuf (7) sur la transmission.
Répartir la graisse entre le soufflet et le tripode (Graisse disponible dans le kit de réparation).
Reposer :
  • Le tripode (6)
  • Le circlips (5)
  • Le bol (4)
Positionner le soufflet (7).
Poser les colliers (1), (2) (voir chapitre correspondant).
4. Remplacement : Soufflet côté roue
4.1. Dépose
Figure : b2fh02od
Déposer :
  • Les colliers (8) et (9)
  • Le soufflet (10)
4.2. Repose
Reposer le soufflet de transmission (10) (neuf).
Remplir le soufflet avec toute la graisse disponible dans le kit de réparation.
Reposer les colliers (8), (9) (voir chapitre correspondant).
5. Colliers de serrage
Figure : b2fh02pd
Positionner le soufflet (7) de transmission (Respecter les repères effectués lors de la dépose).
Reposer les colliers neufs (1) et (2) ; À l’aide de l’outil spécifique (Selon les colliers) :
  • Colliers CLIC ; À l’aide de l’outil [0409]
  • Colliers OETIKER ; À l’aide de l’outil [0412]
Figure : b2fh00bd
Serrer les colliers à oreille ; À l’aide de l’outil [0413] ou [0409] (Selon les colliers).
Figure : b2fh00cd
Serrer les colliers jusqu’au contact ("A" = 0 mm).
Figure : b2fh00dd
Après serrage : Vérifier l’espace "B" = 0,5 à 1 mm.
6. Opération complémentaire
Reposer les transmissions.
