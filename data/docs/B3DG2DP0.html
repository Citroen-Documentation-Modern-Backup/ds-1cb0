B3DG2DP0Dépose - repose : Liaison élastique d’essieu arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5a2034d
[ 1]Grain de repose de l’articulation élastique(-).0549 C2.
[ 2] grain de dépose de l’articulation élastique (-).0549 B2.
[ 3]Contre appui de dépose et repose (-).0549 D2 et (-).0549 E2.
[ 4] potence (-).0549 A.
2. Dépose
Déposer l’essieu arrière(voir opération correspondante).
Repérer le positionnement de cale élastique ( 1) par rapport au bras de suspension.
Figure : b3d200hd
Monter l’outil [ 3] sur le moyeu de l’articulation élastique (1).
Figure : b3d200jd
NOTA : Vérifier que la vis de l’outil [ 4] est bien graissée.
Monter les outils [ 2] et [4] sur l’articulation élastique (1).
Extraire l’articulation élastique ( 1) en vissant la vis de l’outil [4].
Déposer les outils [ 2], [3]et [4].
3. Repose
ATTENTION : Respecter le positionnement des articulations élastiques (1).
Figure : b3d200kd
Positionner l’articulation élastique ( 1) suivant la cote X = 120 °.
Figure : b3d200ld
Monter l’outil [ 3] sur le moyeu de l’articulation élastique (1)(à l’inverse de la dépose).
Figure : b3d200md
Monter :
  • Articulation élastique (1)
  • Les outils [1], [3]et [4]
Serrer la vis de l’outil [ 4] jusqu’à la mise en place de l’articulation élastique (1).
NOTA : Vérifier que la vis de l’outil [ 4] est bien graissée.
Déposer les outils [ 1], [3]et [4].
Reposer l’essieu arrière (voir opération correspondante).
