2.2. Inserts gonflants
Figure : c4e200yd
Les caisses sont livrées avec des inserts gonflants.
Lors de l’échange sur le véhicule d’un élément comprenant un insert gonflant, le réparateur doit effectuer les opérations suivantes :
  • Positionner l’insert gonflant (71) dans l’élément
  • Faire un cordon de mastic de type "H1" sur la périphérie de l’insert avant la pose de la tôle extérieure ou pulvériser de la mousse expansive de type C6 dans le corps creux
2.3. Antigravillonnage
Figure : c4e200zd
Application d’un produit épais pulvérisable pouvant être peint de type " C4" sur parties basses (bas de caisse, plancher avant, passages de roues arrière et bas d’aile arrière). L’épaisseur minimum à appliquer est de 500 microns.
