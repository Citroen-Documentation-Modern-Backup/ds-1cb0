2. Dépose
Lever et caler le véhicule sur un pont à 2 colonnes.
Positionner les roues en ligne droite.
Déposer les roues avant.
Bloquer le volant de direction dans cette position.
Figure : b3e201gd
Repérer la position du cardan de chaque côté.
Desserrer la vis (1).
Déposer vis (2).
Dégager le cardan de direction en le tirant vers le haut.
Figure : b2f200cd
Déposer la goupille et l’écrou ( 3).
Désaccoupler la rotule de direction à l’aide de l’outil [ 1](de chaque côté).
Figure : b2f200dd
Déposer :
  • La goupille (4)(de chaque côté)
  • L’écrou (5)(de chaque côté)
Désaccoupler les rotules de pivots à l’aide des outils [ 1] et [2].
Figure : b1j200dd
Déposer :
  • Les vis (6)
  • Le collier (7)
  • Le tube intermédiaire d’échappement (8)
Figure : b3e201hd
Placer un outil de levage sous le berceau.
Déposer :
  • La fixation de la biellette anticouple ( 9)
  • Les vis (10), (11) et (12)(de chaque côté)
  • Le berceau
3. Repose
Engager le berceau avant ; À l’aide d’un outil de levage.
Reposer :
  • La vis (12) ; Serrer à 4,8 m.daN
  • La vis (11) ; Serrer à 12,8 m.daN
  • La vis (10) ; Serrer à 8,5 m.daN
Dégager l’outil de levage du berceau avant.
Reposer la vis (9) ; Serrer à 12 m.daN.
Repositionner le tube intermédiaire d’échappement ( 8).
Reposer :
  • Les vis (6) ; Serrer à 4,5 m.daN
  • Le collier (7) ; Serrer à 3,2 m.daN
Accoupler les rotules de pivot et de direction.
Reposer :
  • Les écrous (5) ; Serrer à 9,8 m.daN
  • Les goupilles (4)
  • Les écrous (3) ; Serrer les écrous (3) à 3,3 m.daN
  • Les goupilles
  • Le cardan de direction
  • La vis (2) ; Serrer à 2,5 m.daN
  • La vis (1) ; Serrer à 2,5 m.daN
  • Les roues avant ; Serrer à 10 m.daN
Contrôler et régler le parallélisme.
ATTENTION : Lors de toute intervention sur la chaîne cinématique de direction, effectuer le calibrage du capteur de couple de direction à l’aide de l’outil de diagnostic.
